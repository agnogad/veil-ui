## Accessibility

- The button name changes from “Copy” to “Copied”, and a polite live region
  announces the result without moving focus.
- Labels are overridable, so the name can describe the target, such as “Copy
  API key”.
- Clipboard failures leave the button in its original state instead of claiming
  success.
