## Installation

<InstallCommand command="npx veil-ui@latest add flex" />

## Usage

```tsx
import { Flex } from "@/components/ui/flex";

<Flex direction="row" justify="between" align="center">
  <span>Left</span>
  <span>Right</span>
</Flex>;
```

`Flex` is a re-export of `Stack`. Install `stack` alongside it; there is only one
implementation to maintain.

## API reference

See [Stack](/docs/components/stack) for the full API: `direction`, `gap`,
`align`, `justify` and `wrap`.

## Accessibility

- Presentational flex wrapper; it adds no ARIA roles or landmarks.
- All layout props map to static classes, so they are visible to Tailwind's
  compiler.
