## API reference

`Chip` and `chipVariants` re-export [Badge](/docs/components/badge). Use
`muted` for neutral metadata and `secondary` for filters.

## Accessibility

- Chips that can be removed should be buttons with a descriptive accessible
  name; this alias is for static labels.
