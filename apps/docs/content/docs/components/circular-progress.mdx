## Usage

```tsx

<CircularProgress value={72} showValue aria-label="Upload progress" />;
```

## Accessibility

- Exposes `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and
  `aria-valuenow`.
- The SVG and percentage text are hidden from screen readers, which read the
  numeric value instead.
