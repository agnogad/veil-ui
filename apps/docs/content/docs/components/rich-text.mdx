## Installation

<InstallCommand command="npx veil-ui@latest add rich-text" />

## Usage

```tsx
import { RichText } from "@/components/ui/rich-text";

<RichText
  onChange={(html) => setValue(html)}
  defaultValue="<p>Hello <strong>world</strong>.</p>"
/>;
```

This is a deliberately small editor: bold, italic and underline on a
contenteditable surface. For collaborative documents or complex embeds, bring a
dedicated editor such as Tiptap or Lexical.

## Accessibility

- The editable area is a labelled, multiline textbox; the toolbar has a name and
  icon buttons carry labels.
- Toolbar buttons keep the text selection because mousedown is prevented.
- The initial HTML is parsed in an inert document and filtered, so scripts,
  event handlers and `javascript:` URLs never reach the editor.
