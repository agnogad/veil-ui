## Installation

<InstallCommand command="npx veil-ui@latest add icon-picker" />

## Usage

```tsx
import { IconPicker } from "@/components/ui/icon-picker";

<IconPicker value={icon} onSelect={(item) => setIcon(item.name)} />;
```

Pass your own `icons` array when the default set is too small. Each entry is a
name and a lucide component; keeping the array explicit means no icon library is
bundled wholesale.

## Accessibility

- The search field is labelled and filters as you type.
- Every icon button has its name as the accessible label and exposes selection
  through `aria-pressed`.
- An empty result is announced as plain text instead of leaving a blank grid.
