## Accessibility

- Skeletons are `aria-hidden`; they should never be announced.
- Mark the surrounding region with `aria-busy="true"` while loading, and keep
  the skeleton layout close to the final content to avoid layout shifts.
- Respect `prefers-reduced-motion`: the pulse animation is defined in the
  component and pauses when reduced motion is requested.
