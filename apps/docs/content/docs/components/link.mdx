## Usage

```tsx
import { Link } from "@/components/ui/link";

<Link href="/docs">Read the documentation</Link>;
```

For links that look like buttons, use Link Button instead.

## Accessibility

- Always underlined, so links are distinguishable without relying on color.
- External links open in a new tab with `noopener noreferrer` to protect the
  opener page.
- A visible focus ring is rendered for keyboard users.
