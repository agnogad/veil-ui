## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarHeader,
  SidebarItem,
} from "@/components/ui/sidebar";

<Sidebar>
  <SidebarHeader>Acme</SidebarHeader>
  <SidebarContent>
    <SidebarGroup>
      <SidebarGroupLabel>Workspace</SidebarGroupLabel>
      <SidebarItem href="/" active>
        Dashboard
      </SidebarItem>
      <SidebarItem href="/settings">Settings</SidebarItem>
    </SidebarGroup>
  </SidebarContent>
</Sidebar>;
```

## API reference

### Subcomponents

- `Sidebar` — bordered column container.
- `SidebarHeader`, `SidebarContent`, `SidebarFooter` — vertical regions.
- `SidebarGroup`, `SidebarGroupLabel` — labelled link clusters.
- `SidebarItem` — anchor with an `active` state.

## Accessibility

- `SidebarItem` exposes `aria-current="page"` when `active`.
- Group labels are plain text; pair the sidebar with a surrounding
  `<nav aria-label="…">` when it is the primary navigation.
- Rendered links are real anchors, so keyboard and middle-click work.
