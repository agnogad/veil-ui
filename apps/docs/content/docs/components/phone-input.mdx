```tsx

<PhoneInput
  label="Phone number"
  value={phone}
  onValueChange={setPhone}
  onCountryChange={setCountry}
/>;
```

## API reference

- `value` / `defaultValue` hold the local number; `onValueChange` emits the sanitised input.
- `country` / `defaultCountry` control the dial-code picker; `onCountryChange` reports changes.
- Non-numeric characters other than spaces, parentheses and dashes are stripped.

## Accessibility

- The country picker and the number field are both labelled and grouped together.
- The field uses `type="tel"` and `inputMode="tel"` for the right mobile keyboard.
- The country trigger remains a labelled combobox with search.
