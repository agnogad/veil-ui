## Usage

```tsx
import { CodeEditor } from "@/components/ui/code-editor";

<CodeEditor
  label="index.ts"
  language="ts"
  defaultValue={code}
  onValueChange={setCode}
/>;
```

## API reference

- `value` / `defaultValue` hold the source; `onValueChange` emits on every edit.
- `language` labels the header and `showLineNumbers` toggles the gutter.
- `rows`, `readOnly` and `disabled` control the editing surface.

## Accessibility

- The textarea is labelled and keeps the native editing shortcuts.
- Line numbers are decorative and hidden from assistive technology.
- Tab inserts two spaces and restores the caret instead of leaving the field.
