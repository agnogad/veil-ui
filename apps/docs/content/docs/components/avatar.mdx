## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";

<Avatar>
  <AvatarImage src="/ada.png" alt="Ada Lovelace" />
  <AvatarFallback>AL</AvatarFallback>
</Avatar>;
```

## Accessibility

- Always provide `alt` on `AvatarImage`. Use an empty alt only when the avatar
  is decorative and the name appears next to it.
- The fallback is plain text inside the avatar, so it is announced when the
  image is unavailable.
- In a group, add an accessible label such as `aria-label="4 teammates"` to the
  wrapping element.
