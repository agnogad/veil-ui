## API reference

- `value` / `defaultValue` hold a react-day-picker `DateRange`; `onValueChange` fires on each click.
- The first click starts a new range, the second completes it and closes the popover.
- `numberOfMonths` (default `2`), `defaultMonth`, `label` and `disabled` control the panel.

## Accessibility

- The trigger is a labelled `combobox` announcing the formatted range.
- Both month grids are keyboard navigable and share the same selection state.
- Escape closes the popover and restores focus to the trigger.
