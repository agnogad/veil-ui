## Usage

```tsx
import { SocialLoginButtons } from "@/components/ui/social-login-buttons";

<SocialLoginButtons
  providers={["github", "google", "apple"]}
  onSelect={startOAuth}
/>;
```

## API reference

The package exports `social-login-buttons` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Forms use native inputs with associated labels and descriptive error text.
- Submission states are announced through disabled controls and live error messaging.
- Social providers are buttons with discernible provider names.
