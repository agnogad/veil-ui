## Installation

<InstallCommand command="npx veil-ui@latest add input-group" />

## Usage

```tsx
import { InputGroup, InputGroupAddon } from "@/components/ui/input-group";
import { Input } from "@/components/ui/input";
import { AtSign } from "lucide-react";

<InputGroup>
  <InputGroupAddon>
    <AtSign />
  </InputGroupAddon>
  <Input placeholder="you@example.com" aria-label="Email" />
</InputGroup>;
```

## Accessibility

- The wrapper mirrors focus with `focus-within`, so the ring surrounds the whole
  group.
- An inner `aria-invalid` input turns the group border destructive.
- Addons are plain content; decorative icons should be hidden or followed by a
  real label on the input.
