## Usage

```tsx
import { MobileAppShell } from "@/components/ui/mobile-app-shell";
import { MobileBottomBar } from "@/components/ui/mobile-bottom-bar";
import { MobileHeader } from "@/components/ui/mobile-header";

<MobileAppShell
  header={<MobileHeader title="Tasks" subtitle="4 lists" />}
  footer={<MobileBottomBar>{footerActions}</MobileBottomBar>}
>
  <TaskList />
</MobileAppShell>;
```

## API reference

The package exports `mobile-app-shell` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Touch targets are large enough to tap comfortably and keep visible focus rings for keyboard and switch users.
- Gesture interactions (swipe, pull to refresh) have visible button alternatives so they are not the only way to act.
- Sheets, drawers and dialogs follow the underlying accessible primitives for focus trapping and escape handling.
