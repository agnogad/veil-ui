<InstallCommand command="npx veil-ui@latest add snackbar" />

## Usage

```tsx
import {
  Snackbar,
  SnackbarProvider,
  useSnackbar,
} from "@/components/ui/snackbar";

<SnackbarProvider>
  <App />
  <Snackbar />
</SnackbarProvider>;
```

## API reference

The alias maps `Snackbar` → `Toaster`, `SnackbarProvider` →
`ToastProvider` and `useSnackbar` → `useToast` from
[Toast](/docs/components/toast).

## Accessibility

- Snackbars share Toast's labelled live region and dismiss semantics.
