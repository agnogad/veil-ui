## Installation

<InstallCommand command="npx veil-ui@latest add responsive-container" />

## Usage

```tsx
import { ResponsiveContainer } from "@/components/ui/responsive-container";

<ResponsiveContainer maxWidth="md" gutter="lg">
  <Page />
</ResponsiveContainer>;
```

- Presentational wrapper; it adds no roles.
- Resize the viewport to check that content reflows without horizontal
  scrolling.
