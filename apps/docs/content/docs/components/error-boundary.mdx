## Installation

<InstallCommand command="npx veil-ui@latest add error-boundary" />

## Usage

```tsx
import { ErrorBoundary } from "@/components/ui/error-boundary";

<ErrorBoundary onError={(error) => report(error)} fallback={({ reset }) => (
  <button type="button" onClick={reset}>
    Try again
  </button>
)}>
  <Dashboard />
</ErrorBoundary>;
```

## Accessibility

- The default fallback is a `role="alert"` region with the error message and
  a labelled “Try again” button.
- Always provide a way to recover; resetting re-mounts the children.
- Error boundaries do not catch async or event-handler errors; handle those
  locally.
