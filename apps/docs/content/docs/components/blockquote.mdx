## Usage

```tsx
import { Blockquote } from "@/components/ui/blockquote";

<Blockquote cite="Veil UI docs">
  <p>The same code you would write yourself.</p>
</Blockquote>;
```

## Accessibility

- Uses a native `<blockquote>` with the attribution inside a `<footer>` and
  `<cite>`, matching the HTML content model.
- Keep quoted paragraphs inside the blockquote and avoid styling it as a
  heading.
