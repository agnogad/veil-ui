## API reference

- `value` / `defaultValue` hold the selected `Date`; `onValueChange` fires with `undefined` when cleared.
- `placeholder`, `label`, `disabled`, `formatDate`, `fromDate` and `toDate` shape the trigger and the selectable window.
- Selecting a day commits the value and closes the popover.

## Accessibility

- The trigger is a labelled `combobox` with `aria-haspopup="dialog"` and exposes the formatted value.
- The popover traps focus, closes on Escape and returns focus to the trigger.
- The inner calendar keeps its full keyboard grid navigation.
