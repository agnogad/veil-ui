## Installation

<InstallCommand command="npx veil-ui@latest add upload-button" />

## Usage

```tsx
import { UploadButton } from "@/components/ui/upload-button";

<UploadButton
  accept="image/*"
  multiple
  onFiles={(files) => upload(files)}
/>;
```

## Accessibility

- The visible element is a real button named by its label or children.
- The hidden file input is removed from the tab order; the button is the single
  keyboard stop.
- Validate file type and size on the server, not only through `accept`.
