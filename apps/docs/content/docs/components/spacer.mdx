## Installation

<InstallCommand command="npx veil-ui@latest add spacer" />

## Usage

```tsx
import { Spacer } from "@/components/ui/spacer";

<div className="flex items-center">
  <span>Left</span>
  <Spacer />
  <span>Right</span>
</div>;
```

## Accessibility

- Renders an `aria-hidden` element, so it is invisible to assistive technology.
- It must live inside a flex container; otherwise use margins instead.
