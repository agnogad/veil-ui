## Installation

<InstallCommand command="npx veil-ui@latest add feature-card" />

## Usage

```tsx
import { Zap } from "lucide-react";

import { FeatureCard } from "@/components/ui/feature-card";

<FeatureCard
  icon={Zap}
  title="Fast by default"
  description="Sensible defaults with no runtime surprises."
/>;
```

## API reference

The package exports `feature-card` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
