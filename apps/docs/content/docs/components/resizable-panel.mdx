## Installation

<InstallCommand command="npx veil-ui@latest add resizable-panel" />

## Usage

```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable-panel";

<ResizablePanelGroup orientation="horizontal" className="h-64 rounded-md border">
  <ResizablePanel defaultSize="30%">Sidebar</ResizablePanel>
  <ResizableHandle withHandle />
  <ResizablePanel defaultSize="70%">Content</ResizablePanel>
</ResizablePanelGroup>;
```

## Accessibility

- The underlying library provides keyboard resizing and ARIA separator
  semantics.
- The optional grip is decorative; the handle itself remains the interactive
  control.
- Give the group a fixed height, otherwise there is no space to resize.
