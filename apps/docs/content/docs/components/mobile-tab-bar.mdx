## Usage

```tsx
import {
  MobileTabBar,
  MobileTabBarContent,
  MobileTabBarList,
} from "@/components/ui/mobile-tab-bar";

<MobileTabBar defaultValue="home">
  <MobileTabBarContent value="home">{feed}</MobileTabBarContent>
  <MobileTabBarList>{items}</MobileTabBarList>
</MobileTabBar>;
```

## API reference

The package exports `mobile-tab-bar` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Touch targets are large enough to tap comfortably and keep visible focus rings for keyboard and switch users.
- Gesture interactions (swipe, pull to refresh) have visible button alternatives so they are not the only way to act.
- Sheets, drawers and dialogs follow the underlying accessible primitives for focus trapping and escape handling.
