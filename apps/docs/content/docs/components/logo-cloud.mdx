## Installation

<InstallCommand command="npx veil-ui@latest add logo-cloud" />

## Usage

```tsx
import { LogoCloud } from "@/components/ui/logo-cloud";

<LogoCloud
  items={[
    { name: "Acme", src: "/logos/acme.svg" },
    { name: "Globex", href: "https://globex.example" },
  ]}
/>;
```

## Accessibility

- Images always receive the item name as alt text.
- Linked logos keep a visible focus ring and an accessible name from the image
  alt or text label.
- The grid is a plain list, so assistive technology announces the item count.
