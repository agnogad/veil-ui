<InstallCommand command="npx veil-ui@latest add full-screen-layout" />

## Usage

```tsx
import { FullScreenLayout } from "@/components/ui/full-screen-layout";

<FullScreenLayout centered>
  <LoginCard />
</FullScreenLayout>;
```

## Accessibility

- The main region is a `main` landmark.
- Centering is visual only; keep the DOM order logical.
- Avoid trapping scroll inside the layout; it grows with its content.
