## Installation

<InstallCommand command="npx veil-ui@latest add confirmation-dialog" />

## Usage

```tsx
import { ConfirmationDialog } from "@/components/ui/confirmation-dialog";

<ConfirmationDialog
  title="Delete this file?"
  description="This cannot be undone."
  destructive
  confirmLabel="Delete"
  onConfirm={remove}
  trigger={<button type="button">Delete</button>}
/>;
```

## API reference

- `title` is required; `description`, `confirmLabel` and `cancelLabel` fill the body and actions.
- `onConfirm` and `onCancel` run from the action buttons, and `destructive` styles the confirm action.
- `open` / `onOpenChange` allow controlled use; `trigger` renders the default trigger.

## Accessibility

- Rendered as an alert dialog so it interrupts the flow and requires an explicit choice.
- Escape and cancel dismiss it without confirming.
- Confirm and cancel buttons keep their visible text as their accessible names.
