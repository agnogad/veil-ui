## API reference

`Tag` and `tagVariants` re-export [Badge](/docs/components/badge) and its
variants (`default`, `secondary`, `outline`, `muted`, `destructive`).

## Accessibility

- Tags are static text, not interactive; use buttons for dismissible
  filters.
- Because the label is real text, screen readers announce it directly.
