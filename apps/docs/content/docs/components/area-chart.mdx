## Usage

```tsx
import { AreaChart } from "@/components/ui/area-chart";

<AreaChart
  data={data}
  config={{ desktop: { label: "Desktop" }, mobile: { label: "Mobile" } }}
  xKey="hour"
  stacked
/>;
```

## API reference

The package exports `area-chart` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Charts render inside a container with an explicit height so they stay responsive without layout shift.
- Color is never the only encoding; pair charts with labels, summaries or a data table for critical information.
- Tooltips and legends are rendered as HTML, so their text is available to assistive technology.
