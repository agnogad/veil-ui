## Usage

```tsx
import { FileUpload } from "@/components/ui/file-upload";

<FileUpload
  accept="image/*"
  maxSize={5 * 1024 * 1024}
  maxFiles={4}
  onUpload={handleUpload}
/>;
```

## API reference

- `accept`, `multiple`, `maxSize` (bytes) and `maxFiles` constrain what can be added.
- `onFilesChange` fires for every list change; `onUpload` runs from the upload button.
- Rejected files are reported in a `role="alert"` message.

## Accessibility

- The dropzone is a focusable button that opens the file dialog with Enter or Space.
- Each listed file has a dedicated Remove button named after the file.
- Size and count violations are announced through an alert region.
