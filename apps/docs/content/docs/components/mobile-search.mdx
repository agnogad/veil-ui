## Usage

```tsx
import { MobileSearch } from "@/components/ui/mobile-search";

<MobileSearch
  placeholder="Search projects"
  suggestions={["Design tokens", "Release notes"]}
  onSearch={search}
/>;
```

## API reference

The package exports `mobile-search` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Touch targets are large enough to tap comfortably and keep visible focus rings for keyboard and switch users.
- Gesture interactions (swipe, pull to refresh) have visible button alternatives so they are not the only way to act.
- Sheets, drawers and dialogs follow the underlying accessible primitives for focus trapping and escape handling.
