## API reference

- Renders a `role="group"` slide with `aria-roledescription="slide"` and a full-width basis.
- `orientation` adjusts vertical padding for carousels that scroll on the Y axis.
- The carousel package re-exports the same component, so either import works.

## Accessibility

- Slides expose their role and roledescription to screen readers.
- Use with the Carousel region so arrow-key navigation applies.
- Keep slide content meaningful without the visual track context.
