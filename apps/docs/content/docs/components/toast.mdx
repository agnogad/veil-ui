## Usage

```tsx
import { Button } from "@/components/ui/button";
import { Toaster, ToastProvider, useToast } from "@/components/ui/toast";

function SaveButton() {
  const { toast } = useToast();
  return (
    <Button
      onClick={() =>
        toast({
          title: "Changes saved",
          description: "Your profile was updated.",
        })
      }
    >
      Save
    </Button>
  );
}

<ToastProvider>
  <SaveButton />
  <Toaster />
</ToastProvider>;
```

## API reference

### `useToast()`

Returns `{ toast, dismiss }`. `toast(options)` queues a message and returns
its id; `dismiss(id)` closes it early.

`ToastProvider` accepts `duration` and `label` (the screen-reader label for
the region). `Toaster` renders the fixed viewport and must be inside the
provider.

## Accessibility

- Radix Toast announces entries through a labelled live region and pauses
  dismissal while focused or hovered.
- The close control is named “Dismiss notification”.
- Use `destructive` for failures and avoid stacking many toasts at once.
