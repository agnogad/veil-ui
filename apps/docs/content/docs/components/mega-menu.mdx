## Installation

<InstallCommand command="npx veil-ui@latest add mega-menu" />

## Usage

```tsx
import { MegaMenu } from "@/components/ui/mega-menu";

<MegaMenu
  items={[
    {
      label: "Products",
      columns: [
        {
          title: "Platform",
          links: [{ label: "Analytics", href: "/analytics" }],
        },
      ],
    },
  ]}
/>;
```

## Accessibility

- Reuses Navigation Menu behavior: roving focus, Escape to close and
  automatic trigger/panel wiring.
- Column titles are visual headings; each link keeps its own accessible name.
