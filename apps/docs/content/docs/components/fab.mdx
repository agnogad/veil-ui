## Installation

<InstallCommand command="npx veil-ui@latest add fab" />

## Usage

```tsx
import { Fab } from "@/components/ui/fab";
import { Plus } from "lucide-react";

<Fab aria-label="Create item">
  <Plus />
</Fab>;
```

## Accessibility

- Icon-only FABs need an `aria-label`; extended FABs use their visible label.
- Defaults to `type="button"` so it never submits a surrounding form by
  accident.
- Only one FAB should be visible at a time; it marks the single primary action.
