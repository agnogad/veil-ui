## Installation

<InstallCommand command="npx veil-ui@latest add mobile-navbar" />

## Usage

```tsx
import { MobileNavbar } from "@/components/ui/mobile-navbar";

<MobileNavbar
  title="Acme"
  links={[
    { label: "Home", href: "/" },
    { label: "Docs", href: "/docs" },
  ]}
/>;
```

## Accessibility

- The menu button is announced as “Open menu” and exposes
  `aria-expanded` / `aria-controls`.
- The drawer traps focus and closes on Escape through Radix Dialog.
- Mark the current page with `active` so its link gets `aria-current`.
