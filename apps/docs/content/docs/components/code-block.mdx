## Installation

<InstallCommand command="npx veil-ui@latest add code-block" />

## Usage

```tsx
import { CodeBlock } from "@/components/ui/code-block";

<CodeBlock
  code={'const answer = 42;'}
  language="ts"
  filename="answer.ts"
/>;
```

## Accessibility

- The copy button is labelled "Copy code" and switches to "Copied" after a
  successful copy.
- Line numbers are decorative and hidden from screen readers, so the code text
  stays clean when read aloud.
- The sample scrolls horizontally instead of wrapping long lines.
