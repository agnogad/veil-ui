## Installation

<InstallCommand command="npx veil-ui@latest add input" />

## Usage

```tsx
import { Input } from "@/components/ui/input";

<Input type="email" placeholder="you@example.com" />;
```

Always pair an input with a `<label>` or an `aria-label`. Placeholder text is
not a label.

## Accessibility

- The component adds no `aria-*` attributes of its own; supply a label and
  description from the surrounding markup.
- The focus ring is a 3px ring with a border color change, visible on both
  surfaces.
- Invalid inputs must also render a text message — color alone is not enough.
