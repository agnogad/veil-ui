## Usage

```tsx
import { ListItem, ListView } from "@/components/ui/list-view";

<ListView label="Files">
  <ListItem title="proposal.pdf" description="2.4 MB" />
  <ListItem title="hero.png" description="860 KB" />
</ListView>;
```

## API reference

The package exports `list-view` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
