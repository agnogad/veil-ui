## Installation

<InstallCommand command="npx veil-ui@latest add truncated-text" />

## Usage

```tsx
import { TruncatedText } from "@/components/ui/truncated-text";

<TruncatedText lines={3}>{description}</TruncatedText>;
```

## Accessibility

- The full text remains in the DOM, so screen readers and search engines can
  access it; only the visual rendering is clamped.
- Provide a title or detail view when the clipped information is needed to
  complete a task.
