## Installation

<InstallCommand command="npx veil-ui@latest add tabs" />

## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";

<Tabs defaultValue="account">
  <TabsList>
    <TabsTrigger value="account">Account</TabsTrigger>
  </TabsList>
  <TabsContent value="account">...</TabsContent>
</Tabs>;
```

## Accessibility

- Implements the WAI-ARIA tabs pattern: roving tabindex, arrow keys, Home and
  End.
- `TabsList` should have an `aria-label` when the page has more than one tab set.
- Panels are focusable and labelled by their trigger.
