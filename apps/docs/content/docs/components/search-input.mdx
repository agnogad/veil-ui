## Accessibility

- Uses `type="search"`, so the field is announced as a searchbox.
- The leading icon is decorative and hidden from assistive technology.
- The clear action is a button named “Clear search”.
- Render a `<Label>` or pass `aria-label`; a placeholder is not a substitute.
