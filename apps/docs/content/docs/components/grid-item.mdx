## Installation

<InstallCommand command="npx veil-ui@latest add grid-item" />

## Usage

```tsx
import { Grid } from "@/components/ui/grid";
import { GridItem } from "@/components/ui/grid-item";

<Grid cols={12}>
  <GridItem colSpan={8}>Main</GridItem>
  <GridItem colSpan={4}>Aside</GridItem>
</Grid>;
```

## Accessibility

- Presentational wrapper; grid placement is visual only.
- Keep the reading order of the items matching the visual order.
- For responsive placement, add your own `sm:`/`lg:` span classes through
  `className`.
