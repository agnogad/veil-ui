## API reference

`NavigationMenuItem` re-exports the item from
[`Navigation Menu`](/docs/components/navigation-menu); it renders a list item
that participates in the menu's roving focus.

## Accessibility

- Keep items as direct children of `NavigationMenuList`.
- The item itself is presentational; accessible names come from links or
  triggers inside it.
