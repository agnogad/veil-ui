## Usage

```tsx
import { Box } from "@/components/ui/box";

<Box padding="md" className="rounded-lg border">
  Content
</Box>;
```

`asChild` forwards the styles and props to a single child element, so you can
render a link or a custom component without an extra wrapper.

## Accessibility

- Presentational primitive; it adds no roles.
- When `asChild` renders a link or button, that element keeps its own semantics
  and keyboard behaviour.
