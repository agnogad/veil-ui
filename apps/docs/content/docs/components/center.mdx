## Installation

<InstallCommand command="npx veil-ui@latest add center" />

## Usage

```tsx
import { Center } from "@/components/ui/center";

<Center className="h-64">
  <Spinner />
</Center>;
```

## Accessibility

- Presentational wrapper only; it adds no roles.
- Centering is visual. Keep the DOM order logical, and give the centered content
  a real heading or label when it carries meaning.
