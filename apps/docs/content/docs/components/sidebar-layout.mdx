## Installation

<InstallCommand command="npx veil-ui@latest add sidebar-layout" />

## Usage

```tsx
import { SidebarLayout } from "@/components/ui/sidebar-layout";

<SidebarLayout sidebar={<DocsNav />} header={<h1>Theming</h1>}>
  <DocsContent />
</SidebarLayout>;
```

Unlike `AppShell`, this layout is page-level: it constrains width, adds padding
and does not force a viewport height.

## Accessibility

- The sidebar renders as an `aside`; label it when it acts as navigation.
- The layout stacks on small screens. Move the same links into a collapsible
  menu on mobile.
