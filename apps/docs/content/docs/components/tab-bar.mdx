## Usage

```tsx
import {
  TabBar,
  TabBarContent,
  TabBarItem,
  TabBarList,
} from "@/components/ui/tab-bar";

<TabBar defaultValue="overview">
  <TabBarList>
    <TabBarItem value="overview">Overview</TabBarItem>
    <TabBarItem value="activity">Activity</TabBarItem>
  </TabBarList>
  <TabBarContent value="overview">Project overview.</TabBarContent>
  <TabBarContent value="activity">Recent activity.</TabBarContent>
</TabBar>;
```

## API reference

The alias maps `TabBar` → `Tabs`, `TabBarList` → `TabsList`,
`TabBarItem` → `TabsTrigger` and `TabBarContent` → `TabsContent`.

## Accessibility

- Inherits full Tabs behavior: roving focus, `aria-selected` and labelled
  tab panels.
