## Installation

<InstallCommand command="npx veil-ui@latest add action-menu-button" />

## Usage

```tsx
import { ActionMenuButton } from "@/components/ui/action-menu-button";

<ActionMenuButton
  items={[
    { label: "Edit", onSelect: () => openEditor() },
    { label: "Delete", destructive: true, onSelect: () => remove() },
  ]}
/>;
```

## Accessibility

- Built on Radix Dropdown Menu: arrow keys, Home/End and typeahead work out of
  the box.
- Focus returns to the trigger when the menu closes; Escape dismisses it.
- Disabled items stay in the list, marked and skipped by keyboard navigation.
- Give `label` a specific name such as "Project actions" when several menus
  appear on one page.
