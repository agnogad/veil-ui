## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Components</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

`BreadcrumbPage` marks the current item with `aria-current="page"`.

## Accessibility

- Renders a `<nav>` with an accessible name, plus an ordered list for structure.
- Separators are presentational and hidden from assistive technology.
- The collapsed item announces “More pages” through visually hidden text.
- Use `asChild` on `BreadcrumbLink` to keep client-side routing.
