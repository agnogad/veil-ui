## Installation

<InstallCommand command="npx veil-ui@latest add stepper" />

## Usage

```tsx
import { Stepper } from "@/components/ui/stepper";

<Stepper
  current={2}
  steps={[
    { title: "Account", description: "Your details" },
    { title: "Plan", description: "Choose a tier" },
    { title: "Review" },
  ]}
/>;
```

## Accessibility

- Renders an ordered list; the active step gets `aria-current="step"`.
- Completed steps show a check icon and expose `data-state` for styling.
- Descriptions provide extra context without changing the step label.
