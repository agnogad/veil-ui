## API reference

- `value` / `defaultValue` hold the tag strings; `onValueChange` fires on add and remove.
- Enter or comma adds the current text, Backspace on an empty field removes the last tag.
- `maxTags`, `allowDuplicates`, `label`, `placeholder` and `disabled` refine behaviour.

## Accessibility

- Every tag has a Remove button named `Remove tag <text>`.
- The text field is labelled and keeps focus after a tag is added.
- The wrapper shows a focus ring while any child has focus.
