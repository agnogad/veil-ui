## Installation

<InstallCommand command="npx veil-ui@latest add image-card" />

## Usage

```tsx
import { ImageCard } from "@/components/ui/image-card";

<ImageCard
  src="/cover.jpg"
  alt="Cover"
  title="Designing with landscape textures"
  description="How natural palettes shape calm interfaces."
/>;
```

## API reference

The package exports `image-card` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
