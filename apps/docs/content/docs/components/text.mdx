## Installation

<InstallCommand command="npx veil-ui@latest add text" />

## Usage

```tsx
import { Text } from "@/components/ui/text";

<Text size="sm" tone="muted">
  Updated a moment ago
</Text>;
```

multi-line clamping use Truncated Text.

## Accessibility

- Renders a real text element rather than a generic div, so semantics follow
  the chosen `as` value.
- Avoid truncating the only copy of essential information; expose the full value
  through a title or details view when needed.
