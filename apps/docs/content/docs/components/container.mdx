## Accessibility

- Purely presentational. It renders a neutral `<div>`, so landmark semantics
  belong on the surrounding `<main>`, `<section>` or `<header>`.
- Gutters are 16px on mobile and 24px from the `sm` breakpoint up, keeping text
  clear of the viewport edge.
