## Installation

<InstallCommand command="npx veil-ui@latest add dock" />

## Usage

```tsx
import { Home, Settings } from "lucide-react";
import { Dock } from "@/components/ui/dock";

<Dock
  items={[
    { label: "Home", icon: Home, href: "/", active: true },
    { label: "Settings", icon: Settings, href: "/settings" },
  ]}
/>;
```

## Accessibility

- Renders `role="toolbar"` with an accessible name.
- Each icon has a screen-reader-only label; the active item shows a dot and
  `aria-current="page"`.
- Items can be links or buttons depending on whether `href` is set.
