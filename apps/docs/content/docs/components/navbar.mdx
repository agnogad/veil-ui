## Installation

<InstallCommand command="npx veil-ui@latest add navbar" />

## Usage

```tsx
import { Navbar } from "@/components/ui/navbar";

<Navbar>
  <a href="/" className="font-semibold">
    Acme
  </a>
  <nav aria-label="Main" className="ml-auto flex gap-4 text-sm">
    <a href="/docs">Docs</a>
    <a href="/pricing">Pricing</a>
  </nav>
</Navbar>;
```

## Accessibility

- Use a `<header>` landmark and keep the brand link first.
- Wrap links in a `<nav>` with an `aria-label` when several navigations
  coexist on the page.
