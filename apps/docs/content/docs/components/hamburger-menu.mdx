<HamburgerMenu onOpenChange={(open) => console.log(open)} />;

## Accessibility

- Renders a button with a stable accessible name and `aria-expanded`.
- The lines animate into an X while `data-state="open"`.
- Only use it as a visual control for a real menu or drawer.
