## API reference

- `Calendar` forwards every react-day-picker prop, including `mode` (`single`, `multiple`, `range`), `selected`, `onSelect` and `disabled`.
- `classNames` and `components` are merged with the built-in styles so individual cells can be restyled or replaced.
- `showOutsideDays` (default `true`) controls the trailing and leading days of adjacent months.

## Accessibility

- The grid is a table with weekday column headers, so screen readers announce the date column for every cell.
- Arrow keys move by day, Page Up/Down by month and Shift+Page Up/Down by year; Home and End jump to week edges.
- Selected, disabled and outside days are exposed through `data-*` attributes and readable button labels.
