## Installation

<InstallCommand command="npx veil-ui@latest add multiselect" />

## Usage

```tsx
import { MultiSelect } from "@/components/ui/multiselect";

<MultiSelect
  label="Labels"
  options={labels}
  onValueChange={setSelected}
/>;
```

## API reference

The package exports `multiselect` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- The popover is a labelled dialog of checkboxes; selections are announced through the trigger summary.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
