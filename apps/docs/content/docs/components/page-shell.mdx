## Installation

<InstallCommand command="npx veil-ui@latest add page-shell" />

## Usage

```tsx
import { PageShell } from "@/components/ui/page-shell";

<PageShell header={<SiteHeader />} footer={<SiteFooter />} size="md">
  <h1>Page title</h1>
</PageShell>;
```

## Accessibility

- The content region is a single `main` landmark; header and footer are
  complementary regions supplied by you.
- Keep a single `h1` and a logical heading order inside the page.
- Add `skip` links in the header when the navigation is long.
