## Installation

<InstallCommand command="npx veil-ui@latest add segmented-navigation" />

## Usage

```tsx
import { SegmentedNavigation } from "@/components/ui/segmented-navigation";

<SegmentedNavigation
  aria-label="View"
  options={[
    { value: "list", label: "List" },
    { value: "board", label: "Board" },
  ]}
  value="list"
  onValueChange={(value) => console.log(value)}
/>;
```

## Accessibility

- Implements a `tablist` with `tab` children and `aria-selected`.
- Arrow keys move selection; disabled options are skipped.
- Names the group through `label`.
