## API reference

- `value` / `defaultValue` hold the score; `onValueChange` emits `0` when the active star is clicked again.
- `max`, `size` (`sm`, `md`, `lg`), `showValue` and `readOnly` adjust the presentation.
- `disabled` removes it from interaction while `readOnly` keeps it focusable.

## Accessibility

- Implements the WAI-ARIA radiogroup pattern with roving tabindex.
- Arrow keys change the score, Home and End jump to the first and last star.
- Each radio is named `<N> star` / `<N> stars` and exposes `aria-checked`.
