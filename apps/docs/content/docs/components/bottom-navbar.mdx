## Usage

```tsx
import { Home, Settings } from "lucide-react";
import { BottomNavbar } from "@/components/ui/bottom-navbar";

<BottomNavbar
  items={[
    { label: "Home", icon: Home, href: "/", active: true },
    { label: "Settings", icon: Settings, href: "/settings" },
  ]}
/>;
```

## API reference

`BottomNavbar` re-exports [`BottomNavigation`](/docs/components/bottom-navigation)
under a navbar-oriented name; props and accessibility notes are identical.

## Accessibility

- The alias keeps the labelled `<nav>` landmark and `aria-current` handling
  from Bottom Navigation.
