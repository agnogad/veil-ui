## Installation

<InstallCommand command="npx veil-ui@latest add split-button" />

## Usage

```tsx
import { SplitButton } from "@/components/ui/split-button";

<SplitButton
  label="Deploy"
  onClick={() => deploy()}
  items={[
    { label: "Deploy to preview", onSelect: () => deploy("preview") },
    { label: "Redeploy previous build", onSelect: () => redeploy() },
  ]}
/>;
```

## Accessibility

- The trigger has an accessible name that combines the primary label with
  “More … options” (for example “More Deploy options”), plus `aria-haspopup`
  and `aria-expanded`.
- The menu uses `role="menu"` with `role="menuitem"` entries.
- `ArrowDown` and `ArrowUp` cycle through enabled items, `Escape` closes the
  menu and returns focus to the trigger, and an outside pointer press closes it.
