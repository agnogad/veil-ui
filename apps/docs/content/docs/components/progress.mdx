## Accessibility

- Radix exposes `role="progressbar"` with `aria-valuemin`, `aria-valuemax` and
  `aria-valuenow` automatically.
- Always pass an accessible name with `aria-label` or `aria-labelledby`.
- The visible percentage next to the bar should be text, not an image, so it can
  be read and zoomed.
