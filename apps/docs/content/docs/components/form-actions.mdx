## Usage

```tsx
import { FormActions } from "@/components/ui/form-actions";

<FormActions>
  <Button variant="outline">Cancel</Button>
  <Button type="submit">Save</Button>
</FormActions>;
```

## Accessibility

- Renders a plain container; the buttons keep their native semantics.
- Make the primary action the last button in DOM order so keyboard focus reaches
  the safe choice before the destructive one.
- Wrap on small viewports instead of shrinking the buttons below 32px.
