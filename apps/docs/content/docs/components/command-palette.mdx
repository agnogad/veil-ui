## Usage

```tsx

<CommandPalette
  trigger={<button type="button">Command palette</button>}
  items={[{ label: "Settings" }]}
/>;
```

## API reference

`CommandPalette` re-exports [`CommandMenu`](/docs/components/command-menu).
Use it when the trigger is a global shortcut rather than a page control.

## Accessibility

- Inherits the dialog title, combobox search field and option semantics from
  Command Menu.
