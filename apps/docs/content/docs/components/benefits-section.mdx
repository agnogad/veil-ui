## Usage

```tsx

<BenefitsSection
  title="Why teams switch"
  benefits={[
    { title: "Own the source", description: "Components land in your repo." },
  ]}
/>;
```

## API reference

The package exports `benefits-section` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Pages keep a single `h1` in the hero and use `h2`/`h3` for section hierarchy.
- Call-to-action elements are real links or buttons with discernible labels.
- Decorative icons are `aria-hidden` and meaningful images require `alt` text.
