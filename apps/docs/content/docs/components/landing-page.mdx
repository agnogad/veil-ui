## API reference

The package exports `landing-page` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Page templates use semantic landmarks and a single page-level heading.
- Navigation links and actions have discernible names and visible focus styles.
- Decorative imagery uses empty alt text; content images carry descriptions.
