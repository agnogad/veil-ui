## Usage

```tsx
import { FileInput } from "@/components/ui/file-input";

<FileInput
  label="Attachment"
  hint="PDF up to 5 MB"
  accept=".pdf"
  onFilesChange={setFiles}
/>;
```

## API reference

- Wraps a native `<input type="file">` and forwards `accept`, `multiple` and `capture`.
- `onFilesChange` receives the current `FileList` or `null` when cleared.
- `label`, `hint` and `error` are wired with `aria-describedby` and `aria-invalid`.

## Accessibility

- The label is associated with the input through a generated id.
- Error text is announced and marks the field invalid.
- Selected files are listed as plain text, and Clear selection is a normal button.
