`asChild` forwards styles and props to a single child element. Use it for links,
Next.js `<Link>` or any custom trigger.

## Accessibility

- Renders a native `<button>` unless `asChild` is used.
- Includes a 3px focus ring with offset, visible in both themes.
- Disabled buttons use `pointer-events: none` and `opacity: 50%`.
- Icon-only buttons must receive an `aria-label`.
- Loading buttons keep the same accessible name; mark the button `disabled`
  while the request is in flight.
