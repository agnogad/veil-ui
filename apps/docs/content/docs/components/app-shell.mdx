## Installation

<InstallCommand command="npx veil-ui@latest add app-shell" />

## Usage

```tsx
import { AppShell } from "@/components/ui/app-shell";

<AppShell sidebar={<Sidebar />} header={<Topbar />}>
  <Dashboard />
</AppShell>;
```

## Accessibility

- Renders a `main` landmark plus an `aside` when a sidebar is provided.
- Compose the header and sidebar with real `nav`, `header` and heading elements.
- The mobile story is intentionally simple: hide the sidebar and expose the same
  navigation elsewhere, for example through a Drawer.
