## Installation

<InstallCommand command="npx veil-ui@latest add icon-button" />

## Usage

```tsx
import { IconButton } from "@/components/ui/icon-button";
import { Plus } from "lucide-react";

<IconButton aria-label="Add item">
  <Plus />
</IconButton>;
```

## Accessibility

- `aria-label` is required at the type level, so an icon-only button cannot
  ship without a name.
- Icons inherit `currentColor` and are sized to match the button.
- Disabled buttons use `pointer-events: none` and `opacity: 50%`.
