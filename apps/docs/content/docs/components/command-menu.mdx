## Installation

<InstallCommand command="npx veil-ui@latest add command-menu" />

## Usage

```tsx
import { CommandMenu } from "@/components/ui/command-menu";

<CommandMenu
  trigger={<button type="button">Open commands</button>}
  items={[
    { label: "Settings", shortcut: "⌘S" },
    { label: "New project", group: "Create" },
  ]}
/>;
```

## Accessibility

- The dialog has a hidden title and description, and focuses the search
  field on open.
- The input is a `combobox` named by the placeholder; results are options
  with active-descendant tracking.
- Selecting an item runs `onSelect` and closes the dialog.
