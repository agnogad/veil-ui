## Installation

<InstallCommand command="npx veil-ui@latest add back-to-top-button" />

## Usage

```tsx
import { BackToTopButton } from "@/components/ui/back-to-top-button";

<BackToTopButton className="fixed bottom-6 right-6" size="icon" />;
```

The button renders nothing until the page has been scrolled past `threshold`.
Position it yourself with classes; the component only handles visibility and the
scroll action.

## Accessibility

- Icon-only trigger carries an accessible `label`.
- The scroll listener is passive and removed on unmount.
- Respects the platform's smooth-scroll behavior; users who reduce motion get
  the default jump.
