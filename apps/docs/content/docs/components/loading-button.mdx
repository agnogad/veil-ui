## Installation

<InstallCommand command="npx veil-ui@latest add loading-button" />

## Usage

```tsx
import { LoadingButton } from "@/components/ui/loading-button";

<LoadingButton loading={isSaving} loadingLabel="Saving">
  Save changes
</LoadingButton>;
```

## Accessibility

- Sets `aria-busy` and disables the button while loading to prevent double
  submission.
- The spinner is a polite status region with screen-reader-only text.
- Keep the visible label mounted so the accessible name stays stable.
