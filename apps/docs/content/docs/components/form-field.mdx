## Installation

<InstallCommand command="npx veil-ui@latest add form-field" />

## Usage

```tsx
import {
  FormField,
  FormFieldLabel,
  FormFieldDescription,
  FormFieldError,
} from "@/components/ui/form-field";
import { Input } from "@/components/ui/input";

<FormField>
  <FormFieldLabel htmlFor="email">Email</FormFieldLabel>
  <Input id="email" type="email" />
  <FormFieldDescription>We never share it.</FormFieldDescription>
  <FormFieldError>Enter a valid address.</FormFieldError>
</FormField>;
```

## Accessibility

- `FormFieldError` renders `role="alert"` and disappears when there is no
  message, so the region never sits empty.
- Always connect the label with `htmlFor` and the input with a matching `id`.
- Link the error through `aria-describedby` and set `aria-invalid` on the
  control.
