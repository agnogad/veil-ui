## Accessibility

- The root uses `role="alert"`, so it is announced when inserted into the DOM.
  Static alerts rendered on page load can be wrapped in a `div` without the
  role if the announcement would be noisy.
- Do not convey status through color alone; keep an icon or a text label.
- Actions inside the alert should be reachable by keyboard in reading order.
