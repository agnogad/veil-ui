<Stack gap="sm">
  <Item />
  <Item />
</Stack>;

## Accessibility

- Presentational flex wrapper; it adds no ARIA roles or landmarks.
- `direction`, `gap`, `align` and `justify` map to static classes, so they work
  with Tailwind's compiler and never rely on runtime string interpolation.
