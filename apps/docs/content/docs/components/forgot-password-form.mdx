## Usage

```tsx
import { ForgotPasswordForm } from "@/components/ui/forgot-password-form";

<ForgotPasswordForm
  onSubmit={sendResetLink}
  backHref="/login"
/>;
```

## API reference

The package exports `forgot-password-form` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Forms use native inputs with associated labels and descriptive error text.
- Submission states are announced through disabled controls and live error messaging.
- Social providers are buttons with discernible provider names.
