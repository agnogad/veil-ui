## Installation

<InstallCommand command="npx veil-ui@latest add description-list" />

## Usage

```tsx
import {
  DescriptionList,
  DescriptionTerm,
  DescriptionDetails,
} from "@/components/ui/description-list";

<DescriptionList>
  <DescriptionTerm>License</DescriptionTerm>
  <DescriptionDetails>MIT</DescriptionDetails>
</DescriptionList>;
```

## Accessibility

- Uses the native `dl`, `dt` and `dd` elements so term-detail relationships are
  programmatic.
- The inline layout collapses to a single column on narrow screens instead of
  squeezing long values.
