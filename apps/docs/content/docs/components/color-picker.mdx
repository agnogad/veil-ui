## API reference

- `value` / `defaultValue` use hex strings; the input accepts 3- and 6-digit values and normalises them.
- `presets` renders quick swatches with `aria-pressed` state.
- `label`, `disabled` and `className` apply to the trigger and panel.

## Accessibility

- The native color field and hex field each have explicit labels tied to `label`.
- Preset buttons announce `Use #hex` and their pressed state.
- The popover closes with Escape and returns focus to the trigger.
