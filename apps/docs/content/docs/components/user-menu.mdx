## Installation

<InstallCommand command="npx veil-ui@latest add user-menu" />

## Usage

```tsx
import { UserMenu } from "@/components/ui/user-menu";

<UserMenu
  name="Mira Chen"
  email="mira@acme.dev"
  onSignOut={signOut}
/>;
```

The package exports `user-menu` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Forms use native inputs with associated labels and descriptive error text.
- Submission states are announced through disabled controls and live error messaging.
- Social providers are buttons with discernible provider names.
