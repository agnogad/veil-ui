## Usage

```tsx
import { Switch } from "@/components/ui/switch";
import { Label } from "@/components/ui/label";

<div className="flex items-center gap-2">
  <Switch id="airplane" />
  <Label htmlFor="airplane">Airplane mode</Label>
</div>;
```

## API reference

The package exports `switch` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- `Switch` exposes `role="switch"` and Space/Enter toggling; pair it with a `Label` for a discernible name.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
