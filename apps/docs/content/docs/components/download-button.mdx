## Usage

```tsx
import { DownloadButton } from "@/components/ui/download-button";

<DownloadButton href="/files/report.pdf" download="report.pdf">
  Download report
</DownloadButton>;
```

## Accessibility

- It is a real link, so it supports open-in-new-tab, copy-link and the browser
  context menu.
- Add a descriptive label that names the file, not just “Download”.
- `download` is ignored for cross-origin URLs by most browsers.
