## Installation

<InstallCommand command="npx veil-ui@latest add aspect-ratio" />

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";

<AspectRatio ratio={16 / 9}>
  <img src="/cover.jpg" alt="" className="size-full object-cover" />
</AspectRatio>;
```

## Accessibility

- Presentational wrapper; it adds no roles or landmarks.
- Children should fill the box (for example `className="size-full"`) or they
  will only occupy their intrinsic size. Use `object-cover` on images to avoid
  distortion.
