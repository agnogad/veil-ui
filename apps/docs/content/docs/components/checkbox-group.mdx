## Installation

<InstallCommand command="npx veil-ui@latest add checkbox-group" />

## Usage

```tsx
import { CheckboxGroup } from "@/components/ui/checkbox-group";

<CheckboxGroup
  label="Notifications"
  options={[
    { value: "email", label: "Email" },
    { value: "sms", label: "SMS" },
  ]}
  defaultValue={["email"]}
/>;
```

## API reference

The package exports `checkbox-group` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- `CheckboxGroup` renders a labelled `fieldset`; keyboard focus moves through native checkbox controls.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
