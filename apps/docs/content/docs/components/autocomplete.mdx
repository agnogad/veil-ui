  options={cities}
  placeholder="Search cities…"

/>;

## API reference

The package exports `autocomplete` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Suggestions use a listbox pattern with `aria-activedescendant`; Arrow keys move the active option and Escape dismisses the list.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
