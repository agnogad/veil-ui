## Installation

<InstallCommand command="npx veil-ui@latest add tab" />

## Usage

```tsx
import { Tab, TabContent, TabList, TabTrigger } from "@/components/ui/tab";

<Tab defaultValue="account">
  <TabList>
    <TabTrigger value="account">Account</TabTrigger>
    <TabTrigger value="password">Password</TabTrigger>
  </TabList>
  <TabContent value="account">Account settings.</TabContent>
  <TabContent value="password">Password settings.</TabContent>
</Tab>;
```

## API reference

`Tab`, `TabList`, `TabTrigger` and `TabContent` re-export the
[Tabs](/docs/components/tabs) primitives.

## Accessibility

- Radix Tabs provides `tablist` / `tab` / `tabpanel` semantics, arrow-key
  navigation and focus management.
