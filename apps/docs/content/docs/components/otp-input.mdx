## API reference

- `length` (default `6`) sets the number of boxes; `value` / `defaultValue` mirror the code.
- `onValueChange` fires on every edit and `onComplete` when all digits are filled.
- Typing advances focus automatically, Backspace steps back and pasting fills from the current box.

## Accessibility

- Each box is labelled `OTP, digit N` and grouped under a labelled `group`.
- The group uses `inputMode="numeric"` and `autoComplete="one-time-code"`.
- Arrow, Home and End keys move between boxes without changing values.
