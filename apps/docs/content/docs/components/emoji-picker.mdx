<InstallCommand command="npx veil-ui@latest add emoji-picker" />

## Usage

```tsx
import { EmojiPicker } from "@/components/ui/emoji-picker";

<EmojiPicker onSelect={(emoji) => console.log(emoji)} />;
```

## API reference

The package exports `emoji-picker` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Media players use native `<video>` and `<audio>` controls with accessible labels.
- Images require meaningful `alt` text; clickable thumbnails are buttons named `Play <title>`.
- Decorative play overlays, durations and icons are hidden from assistive technology.
