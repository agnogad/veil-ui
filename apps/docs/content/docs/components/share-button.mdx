import {
  ShareButtonBasic,
  ShareButtonOutline,
  ShareButtonWithUrl,
} from "@veil-ui/registry/share-button/demo";
import demoSource from "@/lib/generated/demo-source.json";

## Installation

<InstallCommand command="npx veil-ui@latest add share-button" />

## Usage

```tsx
import { ShareButton } from "@/components/ui/share-button";

<ShareButton title="Veil UI" url="https://veil-ui.dev" />;
```

<ComponentPreview code={demoSource["share-button"].outline}>

The button uses `navigator.share` when the browser exposes it. Otherwise it
copies the URL to the clipboard and confirms with “Link copied”.

## Accessibility

- The label change is announced through a polite live region.
- Clipboard access requires a secure context; handle failures in your own
  analytics if needed.
- The native share sheet is provided by the platform and is fully accessible.
