```tsx

<ExpandableSection title="Shipping" description="Delivery details">

</ExpandableSection>;
```

## API reference

- `title` is required; `description` renders under it and stays visible when collapsed.
- `open` / `onOpenChange` control the state, with `defaultOpen` for uncontrolled use.
- `disabled` blocks toggling while keeping the section readable.

## Accessibility

- The header is a button that reports `aria-expanded`.
- The chevron and border changes are decorative; state is conveyed to assistive technology.
- Body content is removed from the DOM while collapsed.
