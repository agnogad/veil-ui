## Installation

<InstallCommand command="npx veil-ui@latest add form" />

## Usage

```tsx
import { Form, FormSection, FormError } from "@/components/ui/form";

<Form onSubmit={handleSubmit}>
  <FormSection title="Profile" description="How you appear to teammates.">
    {fields}
  </FormSection>
  <FormError>Check the highlighted fields.</FormError>
</Form>;
```

## Accessibility

- Validation messages use `role="alert"`, so they are announced when they
  appear.
- Use real `<label>` elements through `FormField`; placeholders are not labels.
- Keep the submit button inside the form so Enter submits from any field.
