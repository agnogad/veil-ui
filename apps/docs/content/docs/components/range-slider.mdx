## Usage

```tsx
import { RangeSlider } from "@/components/ui/range-slider";

<RangeSlider defaultValue={[20, 80]} min={0} max={100} aria-label="Price range" />;
```

## API reference

The package exports `range-slider` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Each thumb is independently focusable with full keyboard support and exposes its own value.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
