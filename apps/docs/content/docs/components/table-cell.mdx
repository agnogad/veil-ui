## Usage

```tsx
import { Table, TableBody, TableRow } from "@/components/ui/table";
import { TableCell } from "@/components/ui/table-cell";

<Table>
  <TableBody>
    <TableRow>
      <TableCell>Total</TableCell>
      <TableCell>$750.00</TableCell>
    </TableRow>
  </TableBody>
</Table>;
```

## API reference

The package exports `table-cell` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
