## Usage

```tsx
import { Home, Search, User } from "lucide-react";
import { MobileBottomNav } from "@/components/ui/mobile-bottom-nav";

<MobileBottomNav
  items={[
    { label: "Home", icon: Home, href: "/", active: true },
    { label: "Search", icon: Search, href: "/search" },
    { label: "Account", icon: User, href: "/account" },
  ]}
/>;
```

The bar reserves `env(safe-area-inset-bottom)` so labels stay clear of the iOS
home indicator. Pass `onSelect` and omit `href` to control navigation yourself.

## Accessibility

- Renders a labelled `<nav>` landmark with a `Bottom` accessible name.
- The active destination receives `aria-current="page"`.
- Every destination is a native link or button, so it stays keyboard reachable
  and keeps a visible focus ring.
- Badges are visual; make sure any meaningful count is also announced elsewhere.
