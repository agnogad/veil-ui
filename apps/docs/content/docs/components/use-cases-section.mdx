<InstallCommand command="npx veil-ui@latest add use-cases-section" />

## Usage

```tsx
import { UseCasesSection } from "@/components/ui/use-cases-section";

<UseCasesSection
  title="Built for every team"
  cases={[
    { title: "Startups", description: "Ship without a design system team." },
  ]}
/>;
```

## API reference

The package exports `use-cases-section` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Pages keep a single `h1` in the hero and use `h2`/`h3` for section hierarchy.
- Call-to-action elements are real links or buttons with discernible labels.
- Decorative icons are `aria-hidden` and meaningful images require `alt` text.
