## Usage

```tsx

<ImageCarousel images={[{ src: "/one.jpg", alt: "First", caption: "Dolomites" }]} />;
```

## API reference

The package exports `image-carousel` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Media players use native `<video>` and `<audio>` controls with accessible labels.
- Images require meaningful `alt` text; clickable thumbnails are buttons named `Play <title>`.
- Decorative play overlays, durations and icons are hidden from assistive technology.
