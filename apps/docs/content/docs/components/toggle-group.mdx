## Installation

<InstallCommand command="npx veil-ui@latest add toggle-group" />

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";

<ToggleGroup type="single" defaultValue="left" aria-label="Text alignment">
  <ToggleGroupItem value="left" aria-label="Align left">
    Left
  </ToggleGroupItem>
  <ToggleGroupItem value="right" aria-label="Align right">
    Right
  </ToggleGroupItem>
</ToggleGroup>;
```

## Accessibility

- Single mode renders a `radiogroup`; items expose `role="radio"` and arrow-key
  navigation.
- Multiple mode renders a labeled group of toggle buttons with `aria-pressed`.
- Always provide an `aria-label` or `aria-labelledby` on the group.
