## Installation

<InstallCommand command="npx veil-ui@latest add navigation-rail" />

## Usage

```tsx
import { Home, Search } from "lucide-react";
import { NavigationRail } from "@/components/ui/navigation-rail";

<NavigationRail
  items={[
    { label: "Home", icon: Home, href: "/", active: true },
    { label: "Search", icon: Search, href: "/search" },
  ]}
/>;
```

## Accessibility

- Icons are hidden from screen readers; labels are rendered visually hidden
  inside each link.
- The active item gets `aria-current="page"` and a visible indicator bar.
