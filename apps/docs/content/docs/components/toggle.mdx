## Installation

<InstallCommand command="npx veil-ui@latest add toggle" />

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle";
import { Bookmark } from "lucide-react";

<Toggle aria-label="Bookmark this page">
  <Bookmark />
</Toggle>;
```

## Accessibility

- Exposes `aria-pressed` and toggles it on click, Space and Enter.
- Icon-only toggles need an `aria-label`; toggles with text use the text as the
  accessible name.
