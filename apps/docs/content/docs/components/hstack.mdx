<InstallCommand command="npx veil-ui@latest add hstack" />

## Usage

```tsx
import { HStack } from "@/components/ui/hstack";

<HStack gap="sm">
  <Badge>React</Badge>
  <Badge>Tailwind</Badge>
</HStack>;
```

## API reference

`HStack` forwards every `Stack` prop except `direction`, which is fixed to
`row`. Defaults: `gap="md"`, `align="center"` and `justify="start"`.

## Accessibility

- Presentational flex wrapper; it adds no ARIA roles.
- It renders the shared `stack` source, so install it together with `stack`.
