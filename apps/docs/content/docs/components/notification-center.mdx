## Installation

<InstallCommand command="npx veil-ui@latest add notification-center" />

## Usage

```tsx
import { NotificationCenter } from "@/components/ui/notification-center";

<NotificationCenter
  notifications={[
    {
      id: "1",
      title: "Deployment finished",
      description: "Production is live.",
      unread: true,
    },
  ]}
  onMarkAllRead={() => undefined}
  onDismiss={(id) => console.log(id)}
/>;
```

## Accessibility

- The bell trigger is named “Notifications” and appends the unread count,
  e.g. “Notifications (2 unread)”.
- The popover is a labelled dialog with focus management from Radix.
- Entries reuse Notification's unread label and dismiss control names.
