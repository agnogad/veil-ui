## Installation

<InstallCommand command="npx veil-ui@latest add combobox" />

## Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

<Combobox
  label="Assignee"
  options={members}
  onValueChange={setAssignee}
/>;
```

## API reference

The package exports `combobox` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- The trigger and search field are labelled; Arrow keys move through the list and Enter selects the active option.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
