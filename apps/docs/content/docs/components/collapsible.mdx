## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";

<Collapsible>
  <CollapsibleTrigger>Toggle details</CollapsibleTrigger>
  <CollapsibleContent>Hidden details</CollapsibleContent>
</Collapsible>;
```

## API reference

- `Collapsible` supports controlled `open` / `onOpenChange` and `defaultOpen`.
- `CollapsibleTrigger` is a button with `aria-expanded` managed by Radix.
- `CollapsibleContent` removes its children from the DOM when closed.

## Accessibility

- The trigger announces its expanded state and controls the content region.
- Enter and Space toggle it; the trigger stays focusable throughout.
- Use Accordion when several sections share a heading pattern.
