<InstallCommand command="npx veil-ui@latest add number-input" />

## Usage

```tsx
import { NumberInput } from "@/components/ui/number-input";

<NumberInput defaultValue={2} min={1} max={10} aria-label="Quantity" />;
```

## Accessibility

- The input keeps the native `spinbutton` role, so arrow keys and screen
  readers work as expected.
- Step buttons are named “Decrease value” and “Increase value”; raise the value
  with the keyboard using the arrow keys.
- Pass an `aria-label` or pair the field with a visible `<Label>`.
