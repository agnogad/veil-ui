## API reference

- `value` / `defaultValue` hold the ISO country code; `onValueChange` emits the selected code.
- `display` switches the trigger between the country name and its dial code.
- `countries` overrides the built-in list; `countries`, `flagEmoji` and `Country` are exported for reuse.

## Accessibility

- The trigger is a labelled `combobox` that expands into a searchable listbox.
- Typing filters by country name and code; arrows move and Enter selects.
- Flags are decorative and the country name is always part of the option label.
