## Installation

<InstallCommand command="npx veil-ui@latest add field-group" />

## Usage

```tsx
import {
  FieldGroup,
  FieldGroupLegend,
  FieldGroupRow,
} from "@/components/ui/field-group";

<FieldGroup>
  <FieldGroupLegend>Billing address</FieldGroupLegend>
  <FieldGroupRow>{fields}</FieldGroupRow>
</FieldGroup>;
```

## Accessibility

- The `<legend>` names the whole fieldset, so screen readers announce the group
  when entering any field inside it.
- The fieldset resets the browser's default border and padding; spacing comes
  from the grid.
