## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <button type="button">Options</button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Edit</DropdownMenuItem>
    <DropdownMenuItem variant="destructive">Delete</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>;
```

## API reference

### Subcomponents

- `DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent` — root,
  button and portalled panel.
- `DropdownMenuItem` — supports `inset` and `variant="destructive"`.
- `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut` —
  supporting content.

## Accessibility

- Built on Radix Dropdown Menu: typeahead, arrow-key navigation and focus
  return to the trigger.
- Use `DropdownMenuLabel` for section names and keep shortcuts as visual
  hints, not the only affordance.
