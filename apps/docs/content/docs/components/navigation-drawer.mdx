## Installation

<InstallCommand command="npx veil-ui@latest add navigation-drawer" />

## Usage

```tsx
import { NavigationDrawer } from "@/components/ui/navigation-drawer";

<NavigationDrawer title="Menu" trigger={<button type="button">Menu</button>}>
  <nav aria-label="Mobile">
    <a href="/">Home</a>
  </nav>
</NavigationDrawer>;
```

## Accessibility

- Radix Dialog supplies the overlay, focus trap and Escape handling.
- The panel is labelled by its title; the description falls back to a
  screen-reader-only sentence when omitted.
- The close control is named “Close drawer”.
