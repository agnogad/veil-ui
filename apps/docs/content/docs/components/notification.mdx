## Usage

```tsx
import { Bell } from "lucide-react";
import { Notification } from "@/components/ui/notification";

<Notification
  title="Deployment finished"
  description="Production is running commit 4f2a91c."
  timestamp="2 minutes ago"
  icon={Bell}
  unread
/>;
```

## Accessibility

- Unread entries expose a screen-reader-only “Unread” label rather than
  relying on the dot alone.
- The dismiss button defaults to “Dismiss notification” and accepts a
  `dismissLabel` override.
- Timestamps are plain text; include a machine-readable `<time>` element in
  `timestamp` when exact dates matter.
