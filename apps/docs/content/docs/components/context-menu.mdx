## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@/components/ui/context-menu";

<ContextMenu>
  <ContextMenuTrigger>Right-click this area</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>Copy</ContextMenuItem>
    <ContextMenuItem>Paste</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>;
```

## API reference

### Subcomponents

- `ContextMenu`, `ContextMenuTrigger`, `ContextMenuContent` — root and
  trigger area with a portalled panel.
- `ContextMenuItem`, `ContextMenuLabel`, `ContextMenuSeparator` — entries
  and grouping.

## Accessibility

- Radix also opens the menu with the keyboard context-menu key and handles
  focus return.
- Give the trigger visible instructions when right-click is not obvious.
- Do not put destructive-only actions here without a confirmation dialog.
