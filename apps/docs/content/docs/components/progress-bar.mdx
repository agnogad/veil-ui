```tsx

<ProgressBar value={60} aria-label="Upload progress" />;
```

## API reference

`ProgressBar` re-exports [Progress](/docs/components/progress). It takes
`value` from 0 to 100 and all native div attributes.

## Accessibility

- Radix Progress exposes `role="progressbar"` and the value attributes.
- Provide an `aria-label` when no visible label describes the task.
