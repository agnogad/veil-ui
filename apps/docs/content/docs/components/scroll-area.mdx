## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";

<ScrollArea className="h-64 rounded-md border">
  <div className="p-4">Scrollable content</div>
</ScrollArea>;
```

## API reference

`ScrollArea` wraps the Radix root and viewport. Give it a height or width so
there is something to scroll.

### Subcomponents

- `ScrollBar` — scrollbar with its thumb; pass `orientation="horizontal"` for
  horizontal scrollers.

## Accessibility

- The viewport is keyboard scrollable and shows a visible focus ring.
- Scrollbars are pointer affordances; content remains reachable with the
  keyboard and screen readers.
