## API reference

- `value` / `defaultValue` use 24-hour `HH:mm` strings; `onValueChange` emits the committed time.
- `minuteStep` (default `5`) controls the spacing of minute options.
- `label`, `placeholder`, `disabled` and `className` style the trigger and panel.

## Accessibility

- Hours and minutes are separate labelled `listbox` widgets with `aria-selected` on the active option.
- Options are reachable with Tab and activated with Enter or Space.
- A Done action commits the draft and returns focus to the trigger.
