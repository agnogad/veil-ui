## Usage

```tsx
import { Grid } from "@/components/ui/grid";

<Grid cols={3} gap="md">
  <Item />
  <Item />
  <Item />
</Grid>;
```

## Accessibility

- Presentational layout primitive with no ARIA roles.
- Responsive classes are static per `cols` value, so Tailwind can detect them.
- Source order follows DOM order at every breakpoint; use it for reading order,
  not just visual placement.
