## Installation

<InstallCommand command="npx veil-ui@latest add table-of-contents" />

## Usage

```tsx
import { TableOfContents } from "@/components/ui/table-of-contents";

<TableOfContents
  items={[
    { id: "installation", title: "Installation" },
    { id: "usage", title: "Usage", level: 3 },
  ]}
  activeId="usage"
/>;
```

## Accessibility

- Renders a labelled `<nav>` with links to real heading ids.
- The active entry exposes `aria-current="location"`.
- Clicking scrolls the section into view without jumping the URL history.
