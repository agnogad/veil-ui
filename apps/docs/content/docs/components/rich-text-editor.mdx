## API reference

- `RichTextEditor` re-exports the `RichText` component and its props under an editor name.
- `defaultValue` is the initial HTML, `onChange` emits sanitised HTML on input.
- `placeholder` and `disabled` configure the editable surface; formatting buttons apply bold, italic and underline.

## Accessibility

- The editable area is labelled and exposes `aria-multiline`.
- Formatting buttons report their pressed state with `aria-pressed`.
- Output is sanitised against an allowlist before it reaches the DOM.
