<div className="relative min-h-40">
  <LoadingOverlay label="Saving changes" />

## Accessibility

- Sets `aria-busy="true"` on the overlay and announces the label through the
  spinner's status role.
- The visible text is hidden from screen readers to avoid double
  announcements.
- Give the container `relative` positioning for the default overlay.
