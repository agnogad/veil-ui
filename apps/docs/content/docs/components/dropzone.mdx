## API reference

- `onFiles` receives the dropped or picked files as an array.
- `accept`, `multiple` and `disabled` forward to the hidden input.
- `title`, `description` and `icon` customise the visible prompt.

## Accessibility

- The prompt is a `role="button"` target with a visible label and keyboard activation.
- Drag state changes are purely visual; the file dialog remains the accessible path.
- Disabled state removes it from the tab order and ignores drops.
