## Usage

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog";

<AlertDialog>
  <AlertDialogTrigger asChild>
    <button type="button">Delete</button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Delete this workspace?</AlertDialogTitle>
      <AlertDialogDescription>This cannot be undone.</AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>Delete</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>;
```

## API reference

### Subcomponents

- `AlertDialog`, `AlertDialogTrigger`, `AlertDialogContent` — root, trigger
  and portalled modal.
- `AlertDialogHeader`, `AlertDialogTitle`, `AlertDialogDescription`,
  `AlertDialogFooter` — layout and required labelling.
- `AlertDialogAction`, `AlertDialogCancel` — pre-styled destructive and
  outline buttons.

## Accessibility

- Radix Alert Dialog uses `role="alertdialog"`, traps focus and requires an
  explicit action or cancel.
- Escape and overlay clicks cancel; the title labels the dialog and the
  description is announced with it.
- Use it only for consequential confirmations, not informational dialogs.
