The component maps headings, lists, tables, quotes and code to the same
typographic scale used across the docs. Pass `className` to constrain measure,
for example `max-w-prose`.

## Accessibility

- Renders semantic elements for headings, lists, tables and links, keeping the
  document outline intact.
- Tables must include a header row in the markdown source for proper
  associations.
- Raw HTML is not enabled, which removes a common injection vector.
