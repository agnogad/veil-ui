<InstallCommand command="npx veil-ui@latest add pagination" />

## Usage

```tsx
import { Pagination } from "@/components/ui/pagination";

<Pagination page={1} totalPages={12} onPageChange={(page) => console.log(page)} />;
```

## Accessibility

- Renders a labelled `<nav>` with a list of page buttons.
- The current page has `aria-current="page"` and is disabled from repeat
  navigation.
- Prev/next controls are named “Previous page” and “Next page”.
