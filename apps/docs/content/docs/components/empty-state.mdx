## Installation

<InstallCommand command="npx veil-ui@latest add empty-state" />

## Usage

```tsx
import { Inbox } from "lucide-react";
import { EmptyState } from "@/components/ui/empty-state";

<EmptyState
  icon={Inbox}
  title="No messages"
  description="Messages you receive will show up here."
/>;
```

## Accessibility

- The icon is hidden from assistive technology; the title carries the
  meaning.
- Actions are real buttons or links supplied by the caller.
