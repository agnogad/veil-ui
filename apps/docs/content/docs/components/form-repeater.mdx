## Usage

```tsx
import { FormRepeater } from "@/components/ui/form-repeater";

const fields = [
  { name: "name", label: "Guest name" },
  { name: "email", label: "Email", type: "email" },
];

<FormRepeater fields={fields} min={1} max={5} onChange={setRows} />;
```

## API reference

- `fields` describes each input with `name`, `label`, optional `placeholder` and `type`.
- `defaultValue` seeds the rows and `onChange` receives the full row array on every edit.
- `min` / `max` constrain the number of rows; `addLabel` and `disabled` adjust the controls.

## Accessibility

- Each row is announced with its position and every input is named `<Field> row N`.
- Remove buttons are named `Remove row N` and are disabled at the minimum.
- Add and remove actions are plain buttons reachable by keyboard.
