## API reference

- `images` is an array of `{ src, alt }`; `index` / `defaultIndex` and `onIndexChange` track the current image.
- `open` / `defaultOpen` and `onOpenChange` control visibility; `trigger` is optional.
- Navigation wraps around and the counter is announced through `aria-live`.

## Accessibility

- The viewer is a labelled dialog that traps focus until dismissed.
- Arrow keys move between images and the close button is labelled `Close lightbox`.
- Every image carries its `alt` text and the position is announced as `N / total`.
