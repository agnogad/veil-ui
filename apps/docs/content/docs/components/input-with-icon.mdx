## Usage

```tsx
import { Search } from "lucide-react";

import { InputWithIcon } from "@/components/ui/input-with-icon";

<InputWithIcon icon={Search} placeholder="Search…" aria-label="Search" />;
```

## API reference

The package exports `input-with-icon` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- The decorative icon is `aria-hidden`; the input keeps its own accessible name from a label or `aria-label`.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
