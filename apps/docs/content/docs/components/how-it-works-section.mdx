## Usage

```tsx
import { HowItWorksSection } from "@/components/ui/how-it-works-section";

<HowItWorksSection
  title="How it works"
  steps={[
    { title: "Install the CLI", description: "Set up tokens and utils." },
    { title: "Add components", description: "Source lands in your repo." },
  ]}
/>;
```

## API reference

The package exports `how-it-works-section` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Pages keep a single `h1` in the hero and use `h2`/`h3` for section hierarchy.
- Call-to-action elements are real links or buttons with discernible labels.
- Decorative icons are `aria-hidden` and meaningful images require `alt` text.
