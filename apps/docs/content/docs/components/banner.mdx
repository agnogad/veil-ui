## Usage

```tsx
import {
  Banner,
  BannerContent,
  BannerTitle,
  BannerDescription,
} from "@/components/ui/banner";

<Banner>
  <BannerContent>
    <BannerTitle>Update available</BannerTitle>
    <BannerDescription>Reload to apply it.</BannerDescription>
  </BannerContent>
</Banner>;
```

### Subcomponents

- `BannerIcon` — leading icon slot.
- `BannerContent`, `BannerTitle`, `BannerDescription` — text layout.
- `BannerActions` — row of buttons below the copy.
- `BannerClose` — pre-labelled dismiss button.

## Accessibility

- Defaults to a polite status region; pass `role="alert"` for failures.
- `BannerClose` is named “Dismiss banner” by default and accepts a `label`
  override.
- Actions are real buttons, not clickable spans.
