## Installation

<InstallCommand command="npx veil-ui@latest add cluster" />

## Usage

```tsx
import { Cluster } from "@/components/ui/cluster";

<Cluster gap="sm">
  <Badge>React</Badge>
  <Badge>Tailwind</Badge>
  <Badge>Radix UI</Badge>
</Cluster>;
```

items that should reflow on narrow screens.

## Accessibility

- Presentational flex wrapper; it adds no ARIA roles or landmarks.
- `gap`, `align` and `justify` map to static classes, so they work with
  Tailwind's compiler and never rely on runtime string interpolation.
