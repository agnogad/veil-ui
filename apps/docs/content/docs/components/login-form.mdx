## Installation

<InstallCommand command="npx veil-ui@latest add login-form" />

## Usage

```tsx
import { LoginForm } from "@/components/ui/login-form";

<LoginForm
  onSubmit={({ email, password }) => signIn(email, password)}
  forgotHref="/forgot-password"
  signupHref="/signup"
/>;
```

## API reference

The package exports `login-form` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Forms use native inputs with associated labels and descriptive error text.
- Submission states are announced through disabled controls and live error messaging.
- Social providers are buttons with discernible provider names.
