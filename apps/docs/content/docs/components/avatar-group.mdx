## Usage

```tsx
import { AvatarGroup } from "@/components/ui/avatar-group";

<AvatarGroup users={[{ name: "Ada Lovelace" }, { name: "Grace Hopper" }]} />;
```

## API reference

The package exports `avatar-group` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Media players use native `<video>` and `<audio>` controls with accessible labels.
- Images require meaningful `alt` text; clickable thumbnails are buttons named `Play <title>`.
- Decorative play overlays, durations and icons are hidden from assistive technology.
