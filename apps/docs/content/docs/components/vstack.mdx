## Installation

<InstallCommand command="npx veil-ui@latest add vstack" />

## Usage

```tsx
import { VStack } from "@/components/ui/vstack";

<VStack gap="sm">
  <Input placeholder="Email" />
  <Input placeholder="Password" type="password" />
</VStack>;
```

## API reference

`VStack` forwards every `Stack` prop except `direction`, which is fixed to
`column`. Defaults: `gap="md"`, `align="stretch"` and `justify="start"`.

## Accessibility

- Presentational flex wrapper; it adds no ARIA roles.
- Install it together with `stack`, which holds the shared implementation.
