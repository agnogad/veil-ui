## Installation

<InstallCommand command="npx veil-ui@latest add split-layout" />

## Usage

```tsx
import { SplitLayout } from "@/components/ui/split-layout";

<SplitLayout aside={<TableOfContents />}>
  <Article />
</SplitLayout>;
```

## Accessibility

- The aside renders as an `aside` landmark; give it a label when the page has
  more than one.
- DOM order follows `asidePosition`; choose the position that matches the
  reading order you want on mobile.
