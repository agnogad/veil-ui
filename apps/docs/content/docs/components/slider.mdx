<InstallCommand command="npx veil-ui@latest add slider" />

## Usage

```tsx
import { Slider } from "@/components/ui/slider";

<Slider defaultValue={[40]} max={100} step={10} aria-label="Volume" />;
```

## API reference

The package exports `slider` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- `Slider` maps to a Radix slider with Arrow/Page/Home/End keyboard support and `aria-valuenow`.
- Error and disabled states are exposed through native attributes and Radix data attributes.
- Focus-visible rings follow the shared token system in both themes.
