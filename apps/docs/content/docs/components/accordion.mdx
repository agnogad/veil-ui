## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion type="single" collapsible>
  <AccordionItem value="one">
    <AccordionTrigger>First panel</AccordionTrigger>
    <AccordionContent>First content</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## API reference

- `Accordion` requires `type="single"` or `type="multiple"`; single mode accepts `collapsible`.
- `AccordionTrigger` renders inside a heading wrapper with a rotating chevron.
- `AccordionContent` animates its height and hides closed panels.

## Accessibility

- Triggers are buttons with `aria-expanded` and `aria-controls` managed by Radix.
- Up and Down arrows move between triggers; Home and End jump to the edges.
- Each panel is labelled by its trigger through `aria-labelledby`.
