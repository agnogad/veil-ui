## Installation

<InstallCommand command="npx veil-ui@latest add password-input" />

## Usage

```tsx
import { PasswordInput } from "@/components/ui/password-input";

<PasswordInput
  placeholder="Enter your password"
  autoComplete="current-password"
  aria-label="Password"
/>;
```

## Accessibility

- The reveal control is a real button with a changing accessible name:
  “Show password” / “Hide password”.
- It also reports `aria-pressed`, so the current visibility is announced.
- Pair the field with a visible `<Label>` or pass `aria-label`.
