<InstallCommand command="npx veil-ui@latest add timeline" />

## Usage

```tsx
import { Timeline } from "@/components/ui/timeline";

<Timeline
  items={[
    { title: "Order placed", time: "09:12" },
    { title: "Out for delivery", time: "Tomorrow" },
  ]}
/>;
```

## API reference

The package exports `timeline` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
