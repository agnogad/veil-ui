## Installation

<InstallCommand command="npx veil-ui@latest add theme-toggle" />

## Usage

```tsx
import { ThemeToggle } from "@/components/ui/theme-toggle";

<ThemeToggle />;
```

The toggle flips the `dark` class on `<html>` and stores the choice in
`localStorage` under `veil-theme`.

## Accessibility

- The accessible name tracks the next action: “Switch to dark theme” or
  “Switch to light theme”.
- `aria-pressed` reports whether dark mode is active.
- Storage errors are swallowed, so the toggle still works when storage is
  blocked.
