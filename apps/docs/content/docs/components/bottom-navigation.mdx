## Installation

<InstallCommand command="npx veil-ui@latest add bottom-navigation" />

## Usage

```tsx
import { Home, User } from "lucide-react";
import { BottomNavigation } from "@/components/ui/bottom-navigation";

<BottomNavigation
  items={[
    { label: "Home", icon: Home, href: "/", active: true },
    { label: "Account", icon: User, href: "/account" },
  ]}
/>;
```

## Accessibility

- Renders a labelled `<nav>` landmark.
- The active destination receives `aria-current="page"`.
- Badges are purely visual; keep counts out of the accessible name unless
  they change meaning.
