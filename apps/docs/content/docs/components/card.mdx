## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";

<Card>
  <CardHeader>
    <CardTitle>Deployment settings</CardTitle>
    <CardDescription>Configure your project.</CardDescription>
  </CardHeader>
  <CardContent>...</CardContent>
</Card>;
```

## Anatomy

| Slot | Element | Notes |
| --- | --- | --- |
| `Card` | `div` | Vertical flex container with border and shadow |
| `CardHeader` | `div` | Grid with optional action column |
| `CardTitle` | `div` | Medium weight, tight leading |
| `CardDescription` | `div` | Muted, small text |
| `CardAction` | `div` | Top-right slot |
| `CardContent` | `div` | Horizontal padding, no vertical padding |
| `CardFooter` | `div` | Aligned row for actions |

## API reference

All slots accept `React.ComponentProps<"div">`. No custom props are added.

## Accessibility

- Cards are plain containers. Pick the heading level that matches your page —
  `CardTitle` renders a `div` by default.
- Use `asChild`-style composition manually if you need an `article`, `section`
  or `li` wrapper.
- Interactive cards should expose a single focusable element rather than making
  the whole surface a button.
