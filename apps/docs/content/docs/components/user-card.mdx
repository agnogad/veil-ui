## Installation

<InstallCommand command="npx veil-ui@latest add user-card" />

## Usage

```tsx
import { UserCard } from "@/components/ui/user-card";

<UserCard
  name="Ada Lovelace"
  handle="ada"
  bio="Mathematician and writer."
  stats={[{ label: "followers", value: "12.4k" }]}
/>;
```

## API reference

The package exports `user-card` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
