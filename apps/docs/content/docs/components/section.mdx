## Usage

```tsx
import {
  Section,
  SectionActions,
  SectionContent,
  SectionDescription,
  SectionHeader,
  SectionTitle,
} from "@/components/ui/section";

<Section>
  <SectionHeader>
    <div className="grid gap-1">
      <SectionTitle>Team members</SectionTitle>
      <SectionDescription>People with access to this workspace.</SectionDescription>
    </div>
    <SectionActions>
      <Button size="sm">Invite</Button>
    </SectionActions>
  </SectionHeader>
  <SectionContent>...</SectionContent>
</Section>;
```

### Subcomponents

- `SectionHeader` — flex row that keeps the title and actions apart and wraps.
- `SectionTitle` — `h2` heading; pass a different element via `asChild`-style
  composition if your outline requires it.
- `SectionDescription` — muted supporting text.
- `SectionActions` — row of buttons aligned with the header.
- `SectionContent` — grid container for the section body.

## Accessibility

- `Section` renders a real `<section>` landmark region.
- `SectionTitle` renders an `<h2>`; keep the page's heading hierarchy intact by
  styling or swapping the element when the section nests deeper.
- Actions are real buttons supplied by you, not clickable wrappers.
