## Installation

<InstallCommand command="npx veil-ui@latest add error-state" />

## Usage

```tsx
import { ErrorState } from "@/components/ui/error-state";

<ErrorState
  title="Could not load invoices"
  description="Check your connection and try again."
  action={<button type="button">Retry</button>}
/>;
```

## Accessibility

- Rendered inside `role="alert"`, so it is announced when it appears.
- The icon is decorative; keep the title specific so users know what failed.
