## Installation

<InstallCommand command="npx veil-ui@latest add tree-view" />

## Usage

```tsx
import { TreeView } from "@/components/ui/tree-view";

<TreeView
  data={[
    {
      id: "src",
      label: "src",
      children: [{ id: "app", label: "app.tsx" }],
    },
  ]}
  defaultExpanded={["src"]}
/>;
```

## API reference

The package exports `tree-view` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Content uses semantic HTML — lists are lists, tables are tables and metadata uses a definition list.
- Interactive elements are real buttons or links with visible focus states.
- Images require meaningful `alt` text; icons used decoratively are `aria-hidden`.
