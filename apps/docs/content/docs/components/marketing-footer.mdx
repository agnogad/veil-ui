## Installation

<InstallCommand command="npx veil-ui@latest add marketing-footer" />

## Usage

```tsx
import { MarketingFooter } from "@/components/ui/marketing-footer";

<MarketingFooter
  columns={[
    { title: "Product", links: [{ label: "Docs", href: "/docs" }] },
  ]}
  legal={<p>© 2026 Veil UI. All rights reserved.</p>}
/>;
```

## API reference

The package exports `marketing-footer` along with its composable parts. It forwards standard attributes to its root element; see the examples above for the component-specific props.

## Accessibility

- Pages keep a single `h1` in the hero and use `h2`/`h3` for section hierarchy.
- Call-to-action elements are real links or buttons with discernible labels.
- Decorative icons are `aria-hidden` and meaningful images require `alt` text.
